# Квиз по ОС Аврора — Android-версия

Android-порт лабораторной работы № 2 (вариант 17, «Квиз из нескольких вопросов»)
по дисциплине «Проектирование и разработка мобильных приложений».
Дизайн и функции повторяют приложение для ОС Аврора (QML/Silica):

- 10 вопросов с четырьмя вариантами ответа;
- индикатор прогресса из 10 сегментов (зелёный — верно, красный — неверно);
- подсветка правильного/неправильного ответа и сообщение под кнопками;
- вытягиваемое меню (потянуть страницу вниз): «О приложении», «Начать заново»;
- страница результата с разбором ответов;
- страница «О приложении».

Стек: Kotlin + Jetpack Compose, minSdk 26 (Android 8.0+).

## Где взять APK

APK собирается GitHub Actions (`.github/workflows/lab2-android.yml`) при каждом изменении
в `MOBILA/Lab2` и публикуется в релизе **lab2-quiz** (раздел Releases репозитория).
Также его можно запустить вручную: Actions → «Lab2 Quiz — Android APK» → Run workflow.

## Сборка локально

```
cd MOBILA/Lab2
./gradlew assembleDebug
```
Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
